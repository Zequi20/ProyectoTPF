# Adjuntos: figuras, tablas y gráficos

Esta carpeta reúne las figuras, tablas y gráficos activos de la tesis con nombres descriptivos. Los archivos fuente del proyecto no se modifican: las figuras se copian en su formato original y las tablas se extraen como fragmentos LaTeX editables. Los gráficos se conservan como PDF vectoriales.

Inventario: **27 figuras**, **6 gráficos**, **19 tablas editables** y **19 tablas en PNG**. El archivo `indice_adjuntos.csv` relaciona cada adjunto con su etiqueta, título y ubicación de origen.

No se incluyen el logotipo, el membrete, las 72 capturas crudas de `datos/imagenes` ni los entornos comentados, porque no son figuras o tablas activas del documento. Las figuras dibujadas con TikZ se incluyen como PNG renderizados.
